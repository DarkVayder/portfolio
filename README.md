# Portfolio

Rabiu Muhammad — personal portfolio. React + TypeScript + Vite + Tailwind CSS + Framer Motion.

## Scripts

```bash
npm run dev       # start dev server
npm run build     # type-check and build for production
npm run preview   # preview the production build
npm run lint      # run eslint
```

## Structure

- `src/data` — all editable content (profile, experience, projects, tech stack)
- `src/components` — page sections
- `src/components/ProjectCover.tsx` — generated SVG cover per project; swap for a real screenshot by rendering an `<img>` instead once you have one
